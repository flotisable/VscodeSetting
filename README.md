# VscodeSetting
  For backup and share my vscode settings

## Extensions
   | Extension Name                           | Description                                                          |
   |------------------------------------------|----------------------------------------------------------------------|
   | arcticicestudio.nord-visual-studio-code  | [Nord](https://nordtheme.com/) color theme                           |
   | MS-CEINTL.vscode-language-pack-zh-hant   | Traditional Chinese support                                          |
   | asvetliakov.vscode-neovim                | [Neovim](https://neovim.io/) integration                             |
   | ms-vscode-remote.remote-ssh              | [Remote development](https://code.visualstudio.com/docs/remote/ssh)  |
   | ms-vscode-remote.remote-ssh-edit         | Edit SSH config files                                                |
   | llvm-vs-code-extensions.vscode-clangd    | [Clangd](https://clangd.llvm.org/) support                           |
   | ms-vscode.cpptools                       | [C++](https://isocpp.org/) support                                   |
   | mshr-h.veriloghdl                        | [Verilog](https://en.wikipedia.org/wiki/Verilog) support             |

## Keybindings
   | Key            | Action                                                             |
   |----------------|--------------------------------------------------------------------|
   | ctrl+s         | toggle terminal if neovim is setup, save file otherwise            |
   | ctrl+x         | toggle explorer if neovim is setup, cut file in explorer otherwise |
   | ctrl+w k       | focus editor group above                                           |
   | ctrl+w j       | focus editor group below                                           |
   | ctrl+w l       | focus editor group right                                           |
   | ctrl+w h       | focus editor group left                                            |
   | ctrl+w shift+k | move editor group up                                               |
   | ctrl+w shift+j | move editor group down                                             |
   | ctrl+w shift+l | move editor group right                                            |
   | ctrl+w shift+h | move editor group left                                             |
